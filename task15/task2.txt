# Task 2 – Dockerize the Strapi Application

## 📝 Objective

The goal of this task was to containerize the Strapi CMS using Docker so it could run consistently across different environments.

---

## ⚙️ What We Did

1. Created a custom `Dockerfile` to define how the Strapi application should be built into a container.
2. Used the official `node:18-alpine` image as a lightweight base image.
3. Installed all project dependencies using `yarn install`.
4. Configured the container to expose port `1337` — the default port for Strapi.
5. Added `.dockerignore` to avoid copying unnecessary files into the image.
6. Built the Docker image locally using:

   ```bash
   docker build -t strapi-app .



Ran the container using:

bash

docker run -p 1337:1337 strapi-app
Accessed Strapi via http://localhost:1337 and verified it worked correctly inside the container.
